Write code that keeps its promises with Nex

Learn to program, and to engineer software properly. Nex is a small language built for teaching: you state what your code promises, and Nex checks it. Free books take you from your first program to designing real systems.

wallet.nex 
class Wallet
feature
  money: Real

  spend(amount: Real)
  require
    enough: amount <= money
  do
    this.money := money - amount
  ensure
    decreased: money = old money - amount
  end
create
  with_balance(amount: Real) do
    money := amount
  end
end

let w := create Wallet.with_balance(10.2)
w.spend(20.0)
Error: Precondition violation: enough

Small on purpose.

Big in expressive power: contracts, readable syntax, objects, functions and the JVM, all in one compact design. Pick a tab to see each in action.

Classes and inheritance sit beside first-class functions, so you can pick the right tool for each problem.

counter.nex
class Counter
create
  make(start: Integer) do
    this.value := start
  end
feature
  value: Integer
  inc() do
    this.value := this.value + 1
  end
  current(): Integer do
    result := value
  end
end
REPL
> let c: Counter := create Counter.make(10)
> c.inc
> print(c.current)
11
animals.nex
class Animal
feature
  name: String
  speak do print(name) end
create
  named(name: String) do
    this.name := name
  end
end

class Dog
  inherit Animal
feature
  speak do
    print(name + " says woof")
  end
end
REPL
> let a: Animal := create Animal.named("Ko")
> a.speak
Ko
> let d: Animal := create Dog.named("Ki")
> d.speak
Ki says woof

function double(n: Integer): Integer
do

end

Nex compiles to JVM bytecode and can call any Java library. Ship one jar that runs anywhere Java does.

line_buffer.nex
import java.lang.StringBuilder

class Line_Buffer
create
  make() do
    with "java" do
      this.builder := create StringBuilder
    end
  end
feature
  builder: Any
  append_line(s: String) do
    with "java" do
      builder.append(s)
      builder.append("\n")
    end
  end
end
notes
-- import names a Java class
-- with "java" do … end runs host calls
--
-- keep host types behind a small Nex class,
-- so the rest of the program depends on a
-- clear contract, not on Java details.
script.nex
print("Hello from the JVM")

Install in one line.

Linux and macOS (on Windows, use WSL with Ubuntu). Then run nex to open the REPL.

Quick install

Installs the nex command system-wide, with REPL, formatter, docs and compiler tools. If they're missing, it also installs Java and the Clojure CLI, so it asks for your administrator password. It compiles Nex as it goes, which takes a minute or two.

bash <(curl -fsSL https://raw.githubusercontent.com/vijaymathew/nex/main/bootstrap-install.sh) jvm --install-deps
Without sudo

User-local install under ~/.local. Needs Java 17 or later already installed (ask an administrator); the installer fetches everything else. Open a new terminal afterwards so nex is on your PATH.

bash <(curl -fsSL https://raw.githubusercontent.com/vijaymathew/nex/main/bootstrap-install.sh) jvm --prefix "$HOME/.local" --install-deps
Editor support

An Emacs major mode ships in editor/emacs/nex-mode.el, with highlighting, indentation, Imenu and REPL integration (setup guide ↗). Support for other editors is planned.
