This section documents Nex libraries shipped under the repository lib/ directory.

Unlike built-in runtime classes, these libraries may be platform-specific and must be loaded with intern.

Categories

  • Data Libraries - data/Json for JSON parsing and serialization, data/Result and data/Option for typed success/failure and presence/absence, and data/Byte_Array for packed byte buffers
  • IO Libraries - io/Path, io/Directory, io/Text_File, and io/Binary_File for filesystem and file I/O
  • Text Libraries - text/Regex for reusable regular-expression matching and replacement
  • Time Libraries - time/Date_Time and time/Duration for UTC timestamps and time spans
  • Networking Libraries - Http_Client, Http_Server, and TCP wrappers under lib/net

Conventions

  • Library pages state their platform scope explicitly
  • Load library classes with intern path/Class_Name
  • File lookup follows the current intern resolver: loaded file directory, current working directory, then ~/.nex/deps
